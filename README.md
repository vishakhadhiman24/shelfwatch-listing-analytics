# ShelfWatch — Listing Operations & Performance Analytics

## Overview
ShelfWatch is an independent data analytics portfolio project exploring listing prices, reported availability, and review activity in short-term rental listings.

The goal is to turn listing-level data into clear, evidence-based insights that could help inform listing operations and performance monitoring.

## Business Questions
1. How does reported availability vary across listing price ranges?
2. Is review activity associated with reported availability?
3. How does the minimum-night requirement relate to reported availability?

## Dataset
This project uses a publicly sourced Airbnb listings dataset covering US listings in 2023.

The dataset will be assessed for data quality before analysis. Any important exclusions, assumptions, and limitations will be documented.

## Tools
- **Google Sheets** — initial data checks
- **SQL** — querying and analysis
- **Power BI** — dashboard and visual reporting
- **Python (Pandas)** — selective data checks where useful
- **GitHub** — project documentation and version control

## Planned Deliverables
- Documented data-quality checks
- Reusable SQL analysis
- Interactive Power BI dashboard
- Key findings and practical recommendations

## Important Definitions
`availability_365` represents the number of days a listing is reported as available over the next 365 days. It is **not a direct measure of occupancy**.

Relationships identified in this project will be treated as associations, not proof of causation.

## Project Status
In progress — repository setup and initial data-quality review.

## Limitations
This is an independent portfolio project using public data. It is not an official company project and does not use confidential company data. Findings may not represent the full short-term rental market or actual booking performance.
